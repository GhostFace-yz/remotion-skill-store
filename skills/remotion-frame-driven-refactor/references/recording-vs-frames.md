# 录屏 vs 帧驱动：决策文档

> 结论先行：**能用帧算的，绝不用录屏。** 录屏只用来拍"真实界面"，而且拍下来的是素材，不是动画。
>
> 文中的帧数、体积、黑帧比例都来自**一个真实案例**（2218×1440/30fps 录屏，Remotion 4.0.438 + `@remotion/media`，macOS/Apple Silicon），只作量级参考；换素材、换版本都要重测。

## 1. 为什么录屏是下策

把动画录成视频，等于把"可计算的动画"降级成"像素"。代价有五个方面，下面每一条都在同一个案例里真实发生过。

### 1.1 不可改：改一个字要重录全片

背景点阵里烧了 8 句中文文案，录了 2807 帧。后来改一版文案，就是重录一遍全片（几分钟 + 缓存全失效）。如果文案是 DOM/Canvas 帧驱动画的，改一个字符串就行。

### 1.2 不可放大：文字发糊

录的是 1080p 左右，在成片里再放大/被镜头推近就糊。矢量/字体渲染不会有这个问题；就算分辨率够，文字也会带上压缩噪点。

### 1.3 体积与解码：143 MB 素材换来的闪烁

案例里的屏幕录屏 3491 帧、2218×1440、143 MB。成片里每个渲染标签页都要给这条视频开一个 WebCodecs 解码器，跑久了有标签页再也拿不到帧，屏幕就一帧黑一帧亮：

| 并发 | 600 帧里的黑帧（案例） |
|---|---|
| 默认（十几路） | 40 帧（6.6%） |
| 4 | 91 帧（15%） |
| 2 | 0 帧 |

最后靠"分块渲染 + 整段音频"绕过（见 `remotion-chunked-export`）。**纯帧驱动的画面不会有这一类问题**——这正是被录屏逼出来的工程债。

### 1.4 不可搜索、不可本地化、不可改色

录屏里的文字是像素：不能换语言、不能换主题色、不能给某个词加高亮、不能做文字级的动画。

### 1.5 迭代慢

录一遍要几分钟，改一个参数要重录；帧驱动改一个数字，Studio 里立刻能看到。

## 2. 那"真实界面"怎么办

区分两件事：

- **动画**（元素怎么进出、怎么变、怎么排）：必须帧驱动
- **素材**（真实软件长什么样）：可以拍

所以"在 VS Code 里刷 B 站"这种片子，正确做法是：

1. 真实界面**只拍一次**，当素材
2. 素材当**纹理**贴到 3D 屏幕上（见 `remotion-video-texture`），屏幕外的镜头运动、光效、转场全部帧驱动
3. 所有文字、标注、字幕、气泡、图表**一律用 DOM/Canvas 帧驱动重做**，不要烧进录制里

反面教材就是这个项目的背景：为了"点阵文字"好看，把文案和动画一起录成了视频，结果文案不可改、帧数巨大、还要写专门的录制脚本和缓存机制。**应该做的是把点阵文字写成 Canvas/WebGL 组件，用帧驱动逐帧渲染**——慢一点，但可改、可放大、无解码问题。

## 3. 决策表

| 情况 | 做法 |
|---|---|
| DOM / CSS / SVG 动画，能拿到源码 | 帧驱动重构（本 skill 主体） |
| GSAP / anime / framer-motion 时间轴 | 拍平成关键帧表，帧驱动 |
| Canvas 2D 手绘循环 | 把 `t` 换成 `frame`，绘制函数改成无状态 |
| three.js 场景 | `ThreeCanvas frameloop="never"` + 每帧 `advance()` |
| 第三方 WebGL demo，源码改不动 | 录屏（兜底），并按 `recording-vs-frames` 的规范做：固定帧率、分块、缓存 |
| shader 单帧渲染预算爆炸（>2s/帧） | 可以先录，但优先降分辨率/减采样后帧驱动 |
| 真实软件界面 / 终端输出 | 录屏（这是素材，不是动画） |
| 视频/直播内容本身 | 本来就是视频，当素材贴图 |

## 4. 如果非要录：四条规范

1. **虚拟时钟逐帧**，不要真实时间录制（否则掉帧、变速不可控）：`puppeteer` 里 hook 掉 `Date.now`/`rAF`，每帧手动推进再截图。
2. **分块 + 指纹缓存**：300 帧一块，参数哈希进缓存 key，改文案只重录受影响区间。
3. **帧号烧进画面**（可选但强烈建议）：录完随机抽几帧确认帧号对得上，避免"整段偏移一帧"。
4. **与合成总帧数同源**：录制脚本从同一个常量算总帧数，不要两边各写一份。

## 5. 一句话

> 录屏把"可计算的"变成"不可改的"。它的合理位置只有两个：**拍真实界面**，和**拍你改不动的第三方场景**。其余场合用它，都是在给未来的自己挖坑。
